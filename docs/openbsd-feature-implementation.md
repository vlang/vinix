# OpenBSD gap implementation status

This ledger tracks work against [the original 48-finding analysis](openbsd-kernel-gap-analysis.md). The analysis is a dated baseline; this file records subsequent changes. **The complete list is not implemented.** An implemented row closes the named gap, not every OpenBSD capability or every related Linux interface. Partial and in-progress rows explicitly retain work.

Completed changes are consolidated into one integration commit on `master`, preserving its existing commits and concurrent work. The original `codex/openbsd-features` branch is retained: hashes in the development record below identify the tested source revisions, rather than separate commits required in master's cleaned history. Unfinished PAC/BTI and scheduler work remains outside this integration. An unrelated, uncommitted mapping-lifetime refactor is preserved separately in `third_party/openbsd-worktrees/master-wip-preserved` at its original master base.

## Master consolidation verification (2026-10-03)

The consolidation reconciles the session changes with master's pidfd/process retirement, sealed security domains, filesystem permissions, ARM ASIDs, page-table teardown and precise clock counters. Process and thread signal delivery holds the owner/table locks through delivery and job metadata changes; retired threads are checked before borrowing their process. Memory acquisition retains the session's resource pins and validates both global serials and master's local mapping generations. CPU speculation controls use one active policy implementation. Independent reviewers checked these lifetime and lock-order joins.

Both tracked production kernels build with `ALLOC_TRACK=1`. The four-CPU ARM TCG-max core suite passes all **47 required feature checks** and the EXT2 persistence reboot. Production host sanitizer checks pass for private-page acquisition/COW, mapped writeback, sparse blocks, IPv6/multicast and TCP shutdown ownership. Both emitted-C outputs pass the XOM, mounted-disk, endpoint scratch, read-ahead, POSIX timer, resource-accounting, selector, procfs and socket ownership checks. The x86 linked ELF contains **777 retpoline-thunk branches and zero raw indirect CALL/JMP**; host policy and assembly adapters cover 12,288 and 1,024 cases respectively. QEMU cannot establish physical speculation-mitigation effects.

The frozen ARM kernel also passes terminal open/close and rollback races, clock control, the full four-CPU job-control and SysV guests, mount permissions, procfs cycle/concurrent reuse, memory locking, private-page sanitizer checks and all mapped-file writeback modes. EXT2 sparse create/shrink/cleanup passes with both 1 KiB and 4 KiB blocks, including hard-stop disk inspection and e2fsck. Mapped-file hard-stop tests verify shared writes persist and private modifications do not. The SysV fixture was corrected for master's header-inclusive pool; it now also verifies saturated `MSG_COPY` refusal and capacity recovery after consumption. No quota was raised to pass the test.

The ARM desktop sweep completes all **43 required ops/churn/cache/idle/apps/drag measurements**, with no fatal/error or reported write after free. Proc reads/listings and directory listings retain 0 bytes per operation. Directory removal still retains 208 bytes per operation and the broader pipe measurement retains 169 bytes per operation; these unresolved totals are not treated as clean lifetimes. The four 300-run program-churn samples retain 160/48/16/16 KiB. Idle/apps/drag CPU samples are 0.18/0.38/2.53% in this one validation run; they do not establish a comparative speedup.

The merged AMD kernel passes clock control, corrected SysV quotas/lifetimes, bounded pidfd job/exec races and MAC authorization, and the unchanged TLS/LDT/32-bit/IRQ/scheduler/exec compatibility guest. The full mitigation stress guests on max and qemu64 time out in the rapid 1 ms periodic-signal phase. The controlled master max guest also reaches its original 300-second timeout there; independent QMP samples show baseline and quiet merged runs idling in `sched__await`, without establishing the cause.
