# Vinix ISO release, 2026-11-12

Published [iso-2026-11-12](https://github.com/vlang/vinix/releases/tag/iso-2026-11-12)
from `40f802e9575fbb89912518e6b6908ffffc8933fe`. Both ISOs were built from
the same clean source checkout. The release is public and latest, with draft
and prerelease disabled. All nine GitHub asset digests match the local files.
It includes the desktop fix that hides shortcuts for uninstalled applications.

The separate optional ARM64 iOS runtime is retained from `iso-2026-10-26`;
the current runtime requires further compiler migration. Its static ARM64 ELF
headers and published SHA-256 were verified before staging. This exception is
recorded in the release notes. Both desktop images and X11 bundles were rebuilt.

## Validation

All six final QEMU scenarios passed screenshot, keyboard and pointer checks:

| Architecture | Configuration | Desktop screenshot |
|---|---|---|
| AMD64 | BIOS, i440fx, no HPET, one CPU | 40 s |
| AMD64 | UEFI, q35, blank SATA disk installation | 152 s |
| AMD64 | UEFI, reboot from installed system | 21 s |
| ARM64 | UEFI, VirtIO input, blank VirtIO disk installation | 31 s |
| ARM64 | UEFI, reboot from installed system | 31 s |
| ARM64 | UEFI, USB keyboard and tablet | 31 s |

Disk installation checks verified image IDs. ARM64 also verified the installed
system's boot marker. Interleaved ARM64 serial output required the existing
screenshot fallback for desktop detection. VirtualBox was unavailable locally;
its [release CI run](https://github.com/vlang/vinix/actions/runs/43221268237)
was in progress when this report was written.

The original release wrapper built both images, then its old host test client
failed compilation. Boot tests were run separately against those sealed images
from clean validation source `26fb20ff139822f30f671284cdc8651248efb8e2`.
That revision only changes the QMP client's host poll ABI and native-size types.
All three QMP client suites and the screenshot checker suite passed.
