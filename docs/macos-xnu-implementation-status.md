# XNU comparison implementation status

This tracks work against the 49 findings in [the source comparison](macos-xnu-kernel-gap-analysis.md). The comparison remains a dated baseline; this file records changed behavior and remaining work. A partial implementation is not XNU parity.

The requested ten specialists ran in successive groups of three because the environment permits four active agents including the coordinator. Completed source and regression changes were integrated into master through `969b3d5b`, `85fb762f`, `646afb93` and later scoped commits. The original development branches and tested revisions remain available for provenance; their older merge/debug history is not replayed into master. Subsequent master commits, including the OpenBSD consolidation `bd583d2b`, are retained. Historical build/diagnostic worktrees and concurrent foreign working edits are not integration inputs.

This ledger was refreshed on **2026-10-03** alongside [the 49-finding comparison](macos-xnu-kernel-gap-analysis.md). Evidence below is tied to its recorded source revision. A passing earlier guest is not substituted for a failing later stress run.

## Completion rules

A row becomes implemented only after its real behavior, error paths, lifetimes and relevant ABI tests pass. Cross-architecture builds, allocation measurements, and guest tests are recorded separately from host models. Hardware-specific features require a supported platform and restoration/persistence testing. Darwin-specific architectures, signing keys, authenticated-root formats and hibernation boot contracts need explicit native designs; placeholder APIs cannot resolve those findings.
