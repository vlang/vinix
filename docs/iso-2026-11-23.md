Published both desktop ISOs from `cf4e767181b9b14c4426ad19aee59dcbca4756e0`.
GitHub marks the release as latest, both public ISO download links returned
HTTP 200, and all nine published SHA-256 digests match the local assets.
[GitHub release](https://github.com/vlang/vinix/releases/tag/iso-2026-11-23)
