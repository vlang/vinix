# ATL configuration comparison controller

The V module owns provider staging, strict C/V probe build commands, ELF
dependency closure, initramfs contents, guest launch policy and provenance.
The Python entry point retains the parser and initial state-directory creation,
then lends actual objects through the existing Android host bindings. Each
original named assignment remains owned by the entry point's module namespace.
The lazy dependency projection remains a counted Python syntax binding.

The selected provider, patch, independent C fixture, generated V probe, marker
strings and guest timeout are unchanged. Host workflow qualification establishes
controller behavior; it does not establish a new kernel or guest result.
