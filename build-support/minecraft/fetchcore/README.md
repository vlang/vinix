# Minecraft fetcher

V owns retry policy, streamed SHA-1, cache decisions and publication, Mojang
rules, Java compatibility selection, Maven coordinates, library/native
selection, asset deduplication, launch descriptions and complete staging.
The Python entry retains its argument parser, public signatures and module
documentation. Library bindings retain urllib, pathlib, JSON, thread pools,
original exception objects and dynamically looked-up public functions/constants.

`build-support/native_host.py` owns compiler scratch, its installed executable
and each controller process. Retirement closes pipes, waits at most five
seconds, kills and reaps a stalled child, exits outstanding library managers
and restores SIGINT. Streams and pools keep the context manager distinct from
the entered value. Exception-time exit and truth testing run with the original
exception active; successful exits ignore their result. Pool iteration uses
the caller's original entries and counts its current length after retirement.

Frozen-original comparisons cover 284 policy/type/error controls, 48 complete
workflow controls, 18 ownership/retirement controls and eight actual local HTTP
main/cache/retry cases on Darwin ARM64, x86_64 through Rosetta and ARM
ASan/UBSan. The three original independent regressions retain their assertions.
Sixteen signature/documentation contracts, nine CLI/cold controls and 100
repeated hash requests pass on both hosts. Parallel worker invocation order is
scheduler-dependent; those controls compare the exact invocation set, ordered
map results, logs and artifacts. Serial and controlled executor comparisons
retain exact order. Initial ordering-only failures remain in the local receipt.

These tests use ordinary JSON metadata, Path filesystem inputs and byte streams
within the qualified V host array size (under 2 GiB). They do not establish a
new official game download, game launch, kernel build or guest rendering result.
The shared transport and library bindings remain counted as Python; this first
consumer also counts the entire new shared transport overhead.
