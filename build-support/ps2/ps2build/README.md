The PS2 builder policy is native V. The Python entrypoint keeps argparse,
public function signatures, and an interpreter worker callback while the
shared owned-library adapter retains actual Paths, exceptions, archive streams,
and executor objects through synchronous native queries. Download verification,
archive path and size checks, source staging, compiler flags and fingerprints,
ordered archive construction, and license staging live here.

The source archive and Iris implementations stay unchanged. The host controller
uses the ordinary hosted V runtime; it is separate from the freestanding
`vbridge` module. `VINIX_PS2_BUILD_QUERY` can select a prepared controller.
The normal entrypoint resolves the compiler through the shared native-host SDK.
