The sound VM supervisor delegates environment and command construction,
transcript capture, shutdown timing and runner exit reporting to `soundcore`.
The original public `boot` signature and PTY fork/exec remain in Python.
V owns post-fork initialization and ordered retirement and descriptor close. The WAV parser, frequency estimator,
recording checks, fixtures and main result assertions remain independent
counted Python.

The borrowed Package Session ABI preserves actual public callbacks, caller
builtins, lookup and evaluation order, errors, aliases and named lifetimes.
Generator syntax shares a dedicated recent cell, including when supplied
`any` retains the generator. Private bridge traceback shape and arbitrary
near-limit callback recursion budgets are outside the compatibility claim.
Host tools use bundled GC; host controls and PTY fixtures establish no new
Vinix kernel, actual QEMU audio capture or physical playback result.
