Pinned Linux v6.12 kernel/exit.c waitid copies rusage before checking/writing siginfo. A rusage failure returns EFAULT before all siginfo writes, while later siginfo failures preserve copied rusage. With overlapping buffers the six siginfo fields are last. Identical-ELF Linux6.12.51 references qualify this order. Native patch swaps only the existing copyout branches, preserving helpers, error paths, claims, pins and consumption. All fault trials use WNOWAIT; consuming-fault rules, exact partial-rusage copy counts and exact accounting remain separate.
