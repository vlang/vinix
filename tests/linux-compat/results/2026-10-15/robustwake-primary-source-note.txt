Linux v6.12 kernel/futex/core.c handle_futex_death checks owner = uval & FUTEX_TID_MASK. Pending non-PI ownerless entries wake one shared waiter without changing the user word, even when WAITERS/OWNER_DIED flags remain set. Owned entries preserve only WAITERS while setting OWNER_DIED, and wake one ordinary waiter only for non-PI entries with WAITERS. PI-state release has its own queue. The complete tagged source was obtained as base64 from the kernel.org Git mirror, decoded by finish-probe.v and retained with exact URL and SHA-256. The official GitHub raw page was independently inspected. Identical native probe ELFs execute these queue/word predicates against Linux6.12.51 on both architectures. This bounded fix does not change the existing non-atomic owner-word store or claim concurrent mutation, malformed-list or complete PI-state correctness.
