# Portable allocation-benchmark controller

V owns strict build plans, allocator-import assertions, workload and failure
comparisons, provenance records and the host/guest workflow. The Python entry
point keeps its parser, public fixed aliases and narrow object/syntax bindings.
Actual library callables, files, processes, results and exception identities
are borrowed through the existing host transport.

Historical benchmark result snapshots and the independent C reference remain
unchanged. Controller qualification is separate from benchmark performance or
a fresh kernel/guest result.
