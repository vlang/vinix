# M1 platform fixture controller

`run-platform.py` retains the original argparse and temporary-directory owner.
`run-platform.v` owns immutable oracle extraction, source receipts, host and
native compiler recipes, allocation guards, output parity, explicit allocation
site checks and native marker publication. Existing provider/fixture generation
and serial producers remain dependencies. Independent C/V fixture bodies and
assertions are unchanged; their literals receive zero migration credit.

The original eight-group summary, two allocation/free sites, relaxed fixture
imports and nine native markers remain required. Controller qualification does
not establish physical Wi-Fi operation or a new kernel/QEMU result.

The invoking interpreter retains both actual flushed host print calls and the
final native status print. Phase JSON uses response descriptors above standard
slots; close-on-exec standard owners remain private. First Git capture reserves
closed stdout until its pipe is established, then restores it before unchanged
provider/fixture producers. These print/transport/producer leaves receive zero
algorithm credit.

V 0.5.2 `6d549c2` currently emits undeclared `memdup` calls in the
independent platform fixture. The untouched original controller stops at its
strict compiler errors. Controlled compiler artifacts qualify controller policy
and preserve all source bytes and assertions; they do not establish passing
fixture assertions or a QEMU boot.

Commands inherit an explicit snapshot of the invoking interpreter environment,
carried as filesystem-encoded hex pairs. Private launcher/runtime additions do
not become compiler inputs, and POSIX surrogate-escaped bytes remain intact.

The nm text decoding leaf uses the actual invoking Python locale/UTF-8 mode
and universal-newline policy before V applies allocation and Unicode word
guards. This narrow process/text binding receives zero algorithm credit.

The zero-credit nm text decoder receives the actual parent Python locale codec,
including command-line UTF-8 mode, rather than re-reading child defaults.
