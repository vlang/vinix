# M1 platform fixture controller

`run-platform` launches native `run-platform.v`, including its argument parser
and work owner. The eight-group summary, two explicit allocation/free sites,
strict core and relaxed fixture imports, and nine native markers are unchanged.
Module/fixture/serial producers and the guest API use V without an interpreter.

The current independent platform fixture emits undeclared `memdup` calls. Its
strict compiler failure remains visible. This does not establish a passing
current platform fixture, native guest or physical Wi-Fi result.

See [runner qualification](../apple-protocols/runners.md).
