# Wi-Fi native tool helper controller

`run-helpers` launches native `run-helpers.v`. V owns parsing, the private work
directory, frozen header recovery, metadata-preserving provider copies, core
text prefixing, compiler recipes, all object import guards, binary result parity
and native guest receipts. Module and serial generation also use V.

The original SDK behavior, full terminal state, failed-stat output sentinels
and volatile credential wipe checks retain their independent fixture bodies.
The original/V host comparisons pass on ARM and x86 under ASan/UBSan.

See [runner qualification](../apple-protocols/runners.md).
