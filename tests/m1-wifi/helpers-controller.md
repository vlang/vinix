# Wi-Fi native tool helper controller

`run-helpers.py` retains argparse, the temporary work owner, actual flushed print
leaves and private phase transport. `run-helpers.v` owns frozen header extraction,
source receipts, ordered compiler/link recipes, all three object allocation
guards, two-stream binary result parity, pass markers and native guest inputs.
Original locale-sensitive core read/write policy, provider copytree metadata and module/serial producer APIs remain
actual Python leaves with zero algorithm credit. Independent C/V fixture text
and assertions remain untouched and receive zero migration credit.

Phase response and saved descriptors live above standard slots. Child stdin
and public stdout are restored before native commands; close-on-exec standard
owners remain private. Environment snapshots carry filesystem-encoded hex
pairs so private launcher variables and POSIX byte decoding do not alter child
inputs. Native guest command control does not claim a new kernel boot or
physical Wi-Fi result.

The nm text decoding leaf uses the actual invoking Python locale/UTF-8 mode
and universal-newline policy before V applies allocation and Unicode word
guards. This narrow process/text binding receives zero algorithm credit.

The zero-credit nm text decoder receives the actual parent Python locale codec,
including command-line UTF-8 mode, rather than re-reading child defaults.
