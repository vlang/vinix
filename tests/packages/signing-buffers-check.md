# Signing digest, scalar and encoding ownership

The package signing dependency now frees each operation's SHA-512 state,
digests, scalar boxes, conversion buffers and point encodings. Hashes finalize
directly into an owned output buffer through the qualified toolchain's
`checksum_into` interface. Nonce and challenge inputs retain their original
order. Field/scalar arithmetic and signature layout remain unchanged.

The [vendor generator](../../tools/packages/vendor-signing.v) reproduces these
adaptations from immutable upstream blobs. The [provenance record](../../tools/packages/signing/provenance.json)
pins the generated bytes. Source validation refuses removal of digest cleanup,
alongside the existing table, mutation and symlink controls.

The [allocation probe](signing-buffers-check.v) measures key derivation, signing
and verification with no collector. After freeing caller-owned output buffers,
each operation must retain zero tracked V allocation requests. It checks the
first RFC 8032 reference key/signature independently, then runs four cycles at
each of 22 message lengths from zero through 1,024 bytes. These cover SHA-512
padding/block boundaries after the nonce and challenge prefixes. Each cycle
signs, verifies, rejects a modified signature and rejects a truncated signature.
The baseline mode requires positive retained memory for each cold operation.
The distribution driver runs this probe alongside the earlier allocation checks.

```sh
v -nocache -no-skip-unused -d track_heap -gc none -manualfree \
  -path '@vlib|@vmodules|.' -o /tmp/signing-buffers \
  tests/packages/signing-buffers-check.v
/tmp/signing-buffers
```

Lifetime review: digests own their internal arrays and their allocation; both
are freed after finalization. Returned hashes/encodings contain copied bytes,
not references into a freed digest, scalar or point. Scalar reduction reads
owned byte copies during the call; no slice escapes. Scalar boxes are explicit
allocations, freed only after the last reader. Point encoding fills an owned
output array through a private method that returns no receiver reference,
keeping its field receivers on the stack. Generated C and sanitizers check
that lifetime. Generator/identity points return value copies. Public key/signature
buffers remain caller-owned.
No shared cache or concurrent retirement is introduced. The matching Montgomery
encoding caller also returns its owned encoding directly after the old shared
copy helper is removed.

This measures successful signing operations and the specified verification
refusals with the recorded compiler, rather than RSS, kernel heap retention,
every malformed-input/error path, secret zeroization or all package service
allocations. Process constants initialize before tracking. It does not establish
an unbounded publisher lifetime. Broader roadmap 14 enrollment, catalog migration,
graphical integration and application/runtime qualification remain open.

## Recorded results, 2026-10-14

The baseline module was captured from `d94a679e8`. After caller cleanup,
key derivation retained 1,357 bytes, signing 6,544 and verification 3,644.
The adapted implementation retained zero bytes in all three cold measurements
and all 88 repeated cycles. Returned buffers were freed before each measurement
ended; RFC reference bytes and deterministic outputs matched.

Eight host regression runners passed: signing, policy, deployment, publisher
workspace, release, index schema, catalog and composition. The first four and
the new buffer probe passed clang ASan/UBSan with leak detection disabled and
undefined behavior fatal. Source matching refused removal of digest cleanup.
Vendor regeneration, the earlier total/live allocation budgets, signed CLI
lifecycle and 32-publication host probe passed. The distribution driver compiled.
The ledger records 43 successful compile/run results.

Fresh QEMU TCG runs passed on AArch64 (12.8 seconds) and x86_64
(18.5 seconds), using retained committed kernels. Each ran all three
RFC vectors/refusals, all five workspace assertions in one process, and 32
publications/exports with verification in one process, then powered off inside
the 300-second functional allowance. Six artifacts/logs per receipt, generated
C and build logs are hash-pinned. The zero-retention probe runs on the host;
the guest checks establish target functional behavior for the same sources.

The ledger includes the qualified compiler, SHA-512/builtin dependency sources,
baseline module, host runners and both guest artifacts. These results apply
to that recorded toolchain closure. No global toolchain changes were made.
