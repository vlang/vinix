# Offline export metadata in the compact Software reader

An admitted offline export proposal offers **Read review** from the full path
and package stages and the compact view. The shared reader discloses entered
and canonical destinations, target architecture, frozen fingerprint, source
scope, deployment filename/SHA-256 and saved receipt pin, root/package counts,
destination required/available bytes, reserved bytes per filesystem, and cache
acquisition/available bytes. It explains same/separate filesystem accounting,
unchanged installed applications and personal data, original catalog expiry,
publisher enrollment, package permission/licensing/runtime review, and exact
deployment lock bundling. Invalid/nonprintable filesystem bytes appear as
visible escapes; authorization continues to use original frozen bytes.

Entry prepares owned canonical/compact pages. Back/Escape retires both caches
while keeping the frozen intent, receipt pin, package selection/paging, path
stage/position/visited count, draft fields, focus, selection and status. The
modal accepts only page navigation and Back. Confirmation, cancellation,
path-part and package-stage actions, edits, catalog/application requests and
typed/pasted commands cannot mutate the proposal or start a worker. Reading
does not count as visiting the required full-review path parts. Partial and
complete-before-exit reviews and approved publication workers cannot enter it.

Functional fixtures cover 4,096-byte Unicode destinations and deployment
sources, both architectures, shared/separate filesystems, maximum u64 byte
counts, canonical byte escaping, catalog and organization/saved-source exports,
and both full-review stages. They reconstruct canonical text, inspect every
short native line/geometry at 180×220 and 320×240, and check page bounds/keys,
full/compact/tiny resize anchors, modal mutation refusal, fresh re-entry and
unchanged path gates. Existing saved-source digest binding, publisher/license
facts, administrator approval, publication failure and writer close protections
remain in the functional suite.

Mirror navigation and saved-export allocation modes add 1,000 decode/read/page/
render/resize/ignored-publication/Back/cancel/cache-retirement cycles. This is
host UI qualification. No export service/protocol/authorization changes,
whole-service/spawned-worker allocation freedom, guest graphical acceptance or
broader roadmap 14 release completion is implied.
