# Installed application registration admission

The former desktop reader accepted a missing/null package list as an empty
generation, null permissions as an empty grant list and duplicate escaped names
as replacement labels. A generation above u64 was accepted and exposed as the
saturated maximum counter. The package service's state checks refused these
documents. A separate reproduction switches activation to a different generation
that hard-links the already cached state; the former cache skipped the generation
mismatch check. Both reproductions use the actual registry.

Start, Quick Launch and Open With now share an owned bounded presentation
reader. All four envelope fields, each installed `package` object and its seven
presentation fields are mandatory, typed and unique. Explicit empty arrays and
descriptions are supported. Null/coercion, duplicate known/escaped fields,
invalid Unicode, duplicate IDs, unsupported targets/kinds/permissions, malformed
MIME names and incomplete/trailing input are refused. Canonical positive u64
generation targets must match the decoded generation; the maximum value remains
valid. The owner, file-type, permissions and identity-cache checks remain active.

Other service-owned state fields are syntax-checked with bounded nesting and
discarded without retaining payload/provenance trees. This projection does not
validate dependency closure or authorize execution; launch still enters the
package service. Limits are 8 MiB, 4096 packages, five permissions and 128 MIME
types per package, plus the existing string bounds. A refusal publishes no
partial registry and does not cache the damaged file. The desktop caller clears
unavailable entries. Restoring valid metadata permits a normal refresh.

Protocol assertions cover both targets, UTF-8/surrogates, required/duplicate
fields, integer and collection boundaries, valid unused service fields and
malformed/deep extensions. Registry assertions cover actual trusted files,
cached reads, refusal without partial publication, restoration, canonical and
overflowing activation links, and explicit empty generations. A real package
service fixture installs and updates an application/runtime, removes them and
rolls back on each declared architecture, checking the resulting registry and
MIME choices after every activation. Its small synthetic payload is never
executed; it checks actual filesystem transactions and presentation coherence.

The heap fixture measures 1000 wide/current/additive/partially invalid reader
cycles, then 1000 actual registry reload/cache/refusal/architecture-mismatch/generation-mismatch/
retirement cycles. Both paths must retain zero tracked bytes. The full desktop
launcher fixture now requires zero registration retention without a generic
decoder allowance. The maintained driver includes the new heap fixture in its
full run; the Software-only desktop mode is also used for frontend regression.
The maintained launcher fixture applies the existing headless native-control
guard and compiles the pinned compiler's Unix process/thread helper scopes in
a separate C unit generated by V. It retains all package launcher assertions;
the staged ui2 adaptation does not change the dependency checkout.

```sh
V_MACOS_V3_NO_FALLBACK=1 /path/to/v -nocache -no-skip-unused -gc none -manualfree \
  -d track_heap -o /tmp/registration-memory tests/packages/registration-memory.v
/tmp/registration-memory
```

Sanitizer checks disable leak detection and use the same allocation assertions.
Desktop target checks are typechecks; these host fixtures do not claim guest
graphical execution, public publisher enrollment or catalog/runtime acceptance.

All protocol runners, registry assertions, real host install/update/remove/rollback checks and the maintained Software/desktop launcher driver passed. Both desktop target configurations typechecked. Reader and registry fixtures retained **zero tracked bytes** over 1000 cycles; the final registry checks include generation-cache mismatch refusal. Protocol, registry, lifecycle and heap checks passed clang ASan/UBSan with leak detection disabled.
