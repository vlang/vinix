# CPU mitigation host controller

The Python entry point keeps its original temporary-directory owner and `main`
result. V owns the source-copy order, exact compiler arguments, unchanged
sanitizer profile, Unicode allocator audit and test launch. The independent
adapter and assertion literals are byte-identical to the original committed
controller and receive zero translation credit. Production CPUID/MSR policy,
allocation failure/retry, 12,288 combinations and readback assertions remain
unchanged. Host controller results establish no new kernel, QEMU or hardware
mitigation result.

Private environment transport preserves the actual caller's POSIX bytes,
including surrogate-escaped names and values, without runtime-added variables.
