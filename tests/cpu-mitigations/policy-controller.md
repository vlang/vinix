# CPU mitigation host controller

The native `check-policy` entry owns its private temporary directory, source-copy
order, compiler arguments, unchanged sanitizer profile, Unicode allocator audit
and test launch. It captures `nm` directly with strict UTF-8 and universal
newlines. The independent
adapter and assertion literals are byte-identical to the original committed
controller and receive zero translation credit. Production CPUID/MSR policy,
allocation failure/retry, 12,288 combinations and readback assertions remain
unchanged. Host controller results establish no new kernel, QEMU or hardware
mitigation result.

Child processes inherit the native caller's environment and standard descriptors;
the Python environment/descriptor transport and interpreter leaf are retired.
The original adapter and assertion bytes are retained, and the native owner
cleans private files on success and returned errors. See [host-policy](../host-policy/README.md)
for qualification and the maintained launch commands.
