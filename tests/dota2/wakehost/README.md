# Native WAKE_OP fixture staging

V owns source validation, explicit translator selection, linker arguments,
fixture copies and links, init generation, archive ownership, measured input
hashes, isolated VM environment and result publication. The public Python
entry point retains argparse and original CLI validation. Its independent
C WAKE_OP fixture and linker script remain unchanged.

Calls borrow their actual targets before evaluating arguments. Expression
operands retire at the original call boundaries, while returned aliases retain
their own IDs. Inherited environment and input mappings are copied before
explicit path conversion and verdict callbacks.

`_wake_native.py` binds actual caller stdlib objects and preserves wide
integers, paths, public callbacks, exceptions and distinct managers/entered
values. Tuple/mapping syntax bindings remain counted Python. `wakeguest`
owns capture and the original shutdown windows. Host qualification is
separate from guest execution; receipts identify prepared artifacts used.
