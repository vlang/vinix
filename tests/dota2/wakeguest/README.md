# Native WAKE_OP guest supervision

V retains child-only boot-root resolve, command/environment identity, the
one-second select, 65536-byte read and original end/panic markers. Shutdown
requests monitor exit and closes the master, then retains the three original
five-second wait windows with TERM/KILL and owned-PID fallback.

Ownership checkpoints bound serial temporaries. A successful read replaces
the previous raw block; the last block, entered log, absolute deadline and
PID/master values survive shutdown and host result publication. A distinct
temporary manager retires after its original context exit. GAP atomic
close/wait consumes FD/PID ownership before
replies. A completed public call returns process responsibility to its
original caller, including `False` and original errors. A broken query before
its completion marker retains the emergency guardian.
