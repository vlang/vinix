# QMP input policy

V owns key and pointer event construction, absolute scaling, monitor startup,
QMP request and reply decisions, typing and Command-Tab sequencing. Public
Python signatures, key-name maps and the CLI remain counted Python. Library
objects and arbitrary-width numeric operations stay in the invoking interpreter
through the existing borrowed-object binding; original socket and stream owners
remain attributes of the caller's monitor.

Independent original-source fixtures exercise event values, hook identity,
errors and operation order. Host socket tests qualify the QMP protocol, without
claiming a new kernel build, desktop boot or rendering result.
